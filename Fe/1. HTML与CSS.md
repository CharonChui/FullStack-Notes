
- HTML是描述文档结构和含义的标记语言。 
- CSS是给结构设置样式和布局
- JavaScript负责交互与动态行为

浏览器读取HTML构建DOM树，读取CSS构建样式规则，计算元素样式与几何位置，再把像素绘制到屏幕。 现代浏览器还会对部分绘制工作进行合成和并行优化。  

类比Android的布局过程：HTML像带语义的View树，CSS规则参与测量与布局，最终由渲染引擎绘制。  
但浏览器不是把XML编译成APK，文档可由网络即时获得、CSS级联、Web标准和响应式视口共同影响结果。 

## HTML

HTML不是编程语言，是标记语言，用标签描述这段内容是什么。    
浏览器先把HTML解析成DOM(Document Object Mode，文档对象模型)树，CSS和JavaScript都在这棵树上工作。   



## CSS
把DOM的结构编程可用的布局。  他不是给元素涂颜色，而是一套规则系统。

规则由选择器和声明组成。
- 选择器选中元素
- 声明改变属性
- 多条规则冲突时按层叠/特异性/顺序决定结果
- 每个元素在盒模型和布局算法中占空间

CSS文件如何被浏览器加载？ 
HTML head中会建立连接: 
```html
<!-- rel 说明链接关系是样式表；href 相对 index.html 所在目录。 -->
<link rel="stylesheet" href="styles.css" />
```
浏览器拿到HTML后会请求styles.css，解析规则，再计算每个DOM节点的最终样式。 


```css
/* :root 选择文档根元素 html；这里放整个页面可继承的默认值。 */
:root {
  /* font-family 按顺序选择第一个可用字体；sans-serif 是最后兜底。 */
  font-family: system-ui, -apple-system, "Segoe UI", sans-serif;
  /* color 是文字前景色；#172033 是 6 位十六进制 RGB 颜色。 */
  color: #172033;
  /* background 是背景简写属性；这里仅设置背景颜色。 */
  background: #f3f5f9;
}

/* * 是通配选择器；逗号表示“同时选择这些选择器匹配的元素”。 */
*,
*::before,
*::after {
  /* border-box 让 width/height 包含 padding 和 border，计算尺寸更直观。 */
  box-sizing: border-box;
}

/* body 默认有浏览器 margin；归零以便自己决定页面边距。 */
body {
  margin: 0;
}

/* .site-header 选择 class 含 site-header 的元素；点号是 class 选择器。 */
.site-header {
  /* display:flex 让直接子元素参加弹性盒布局，而不是普通块布局。 */
  display: flex;
  /* align-items 是 flex 交叉轴（默认竖直方向）对齐方式。 */
  align-items: center;
  /* justify-content 是主轴（默认水平方向）如何分配剩余空间。 */
  justify-content: space-between;
  /* padding 是内容到边框的内间距：上下 1rem，左右 2rem。 */
  padding: 1rem 2rem;
  background: white;
  /* border-bottom 只设置下边框：宽度、线型、颜色。 */
  border-bottom: 1px solid #d9dfeb;
}

/* 空格表示后代选择器：选 site-header 内任意层级的 nav。 */
.site-header nav {
  display: flex;
  /* gap 是 flex/grid 子项之间的间隔，不会额外占首尾空间。 */
  gap: 1rem;
}

/* :hover 是伪类，指针悬停时才匹配。 */
a:hover {
  color: #2451c6;
}

/* .page 是 main 的内容容器。 */
.page {
  /* min() 取两个值中较小者：小屏留 2rem 空隙，大屏最大 760px。 */
  width: min(100% - 2rem, 760px);
  /* 3rem 是上下 margin；auto 是左右自动分配空白，因此块居中。 */
  margin: 3rem auto;
}

/* 逗号组合两个选择器，共用同一套声明。 */
.intro,
.panel {
  margin-bottom: 1.25rem;
}

.panel {
  padding: 1.5rem;
  background: white;
  border: 1px solid #d9dfeb;
  /* border-radius 让边框四角圆润；它不自动裁剪内部内容。 */
  border-radius: 0.75rem;
  /* box-shadow: x 偏移 y 偏移 模糊半径 颜色。 */
  box-shadow: 0 8px 24px rgb(23 32 51 / 8%);
}

/* .task-form 是 form，自身用 grid 排列 label/input/button。 */
.task-form {
  display: grid;
  gap: 0.75rem;
}

/* 属性选择器：只选 type 属性恰为 text 的 input。 */
input[type="text"] {
  width: 100%;
  min-height: 2.75rem;
  padding: 0.5rem 0.75rem;
  border: 1px solid #aeb8cb;
  border-radius: 0.5rem;
  /* font:inherit 明确继承父元素字体相关属性，输入框不再用浏览器默认字体。 */
  font: inherit;
}

button {
  min-height: 2.75rem;
  padding: 0.5rem 1rem;
  border: 0;
  border-radius: 0.5rem;
  color: white;
  background: #3158d4;
  font: inherit;
  cursor: pointer;
}

/* :focus-visible 通常在键盘聚焦时显示，避免鼠标点击时多余焦点框。 */
input:focus-visible,
button:focus-visible,
a:focus-visible {
  outline: 3px solid #f2b84b;
  outline-offset: 2px;
}

.task-list {
  display: grid;
  gap: 0.5rem;
  /* ul 默认有内边距和项目符号；本任务列表不需要它们。 */
  padding: 0;
  list-style: none;
}

.task-item {
  display: flex;
  align-items: center;
  gap: 0.5rem;
  padding: 0.75rem;
  background: #eef2ff;
  border-radius: 0.5rem;
}

/* :checked 是复选框被勾选时匹配；+ 是紧邻的同级元素选择器。 */
input[type="checkbox"]:checked + label {
  color: #61708c;
  text-decoration: line-through;
}

@media (max-width: 480px) {
  /* @media 是条件规则；视口不大于 480px 时，里面规则才参与层叠。 */
  .site-header {
    flex-direction: column;
    align-items: flex-start;
    gap: 0.75rem;
  }
}
```
选择器定位元素，声明是属性和值。 
常用的选择器有： 
- 元素选择器
- id选择器
- 类选择器
- 属性选择器和伪类

盒模型：每个元素可以看作是一个盒子： 
- 内容区
- 内边距padding
- 边框border
- 外边距margin

#### 布局：Flex、Grid、定位
- 正常流：块元素通常从上往下排，段落、文章使用
- Flexbox：适合一维排列，一行或一列，例如导航栏、按钮组、卡片内的横向对齐
- Grid：适合二维行列布局，例如仪表盘和卡片网格
- Position：保留原布局位置并成为定位参照
