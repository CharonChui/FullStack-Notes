
JavaScript是浏览器的编程语言，他可以读取DOM、注册事件、修改DOM、发送网络请求，在浏览器和Node.js时不同的运行环境。 

- 浏览器提供DOM、事件、fetch、localStorage等Web API。
- Node.js提供文件、进程、网络服务器等服务端API。

html中关联JavaScript：  
```html
<!-- script 创建脚本元素；src 要求浏览器加载同目录 app.js。 -->
<!-- defer：下载可与 HTML 解析并行，但执行一定等整个 DOM 解析结束。 -->
<script src="app.js" defer></script>
```

执行顺序： 
- 浏览器解析HTML，遇到defer脚本就下载，DOM解析完成后执行app.js
- app.js中如果有querySelector得到对象引用通过addEventListener登记函数，但此刻没有执行回调
- 用户提交后，浏览器调用回调，把event传进去
- 执行毁掉里面的逻辑


## JavaScript基础

```js
// 常量
const title = "hello";
// 变量
let completed = false;
const tags = ["hello", "world"];
// object用花括号保存一条有名字字段的记录
const task = {id: 7, title, completed};
function toogle(value: boolean): boolean {
    return !value;
}
```
- 优先用const，重新赋值时用let，避免var的函数作用域和提升规则
- JavaScript有string、number、boolean、undefined、null、symbol等基本类型，object是对象

##### 异步、Promise和事件循环

网络请求要等待服务器。若主线程同步等待，页面就会卡死。   
Promise表示未来可能成功或失败的结果。 
async、await是更容易读的Promise语法。 
await只暂停当前async函数的后续部分，不冻结整个页面。
```js
async function loadTasks(): Promise<Task[]> {
    try {	
        const response = await fetch("/api/tasks");
        if (!response.ok) {
            throw new Error("failed");
        }
        return response.json() as Promise<Task[]>;
    } catch (error) {
        console.error("fail");
    }
}
```

await会暂停当前async函数的后续执行，但不会冻结整个JavaScript线程。   
运行环境在I/O完成后安排回调继续执行。   
Node.js会用事件循环处理许多I/O等待。
单个JavaScript回调若执行了长时间CPU计算，仍会堵住同一进程的其他请求。


### TypeScript

TypeScript（TS）是 JavaScript 的超集：你写类型标注，编辑器和编译器用它检查；产物仍是 JavaScript。**类型不会在浏览器或 Node 运行时自动验证数据。** 网络 JSON、表单、环境变量、数据库结果依然必须自己验证。
