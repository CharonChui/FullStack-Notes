
原生JavaScript中，你手工createElement、append、改DOM。React改成另一种约定：你描述当前状态下UI应该长什么样，状态变换后React计算并提交最少的DOM更新。   

React不会消灭HTML/CSS/JS，它建立在三者之上。    

静态页面适合显示固定内容；当页面需要局部更新、复杂交互、路由和共享状态时，前端框架可以管理 UI 结构和更新过程。React 把界面拆成组件：给定 props 和 state，组件描述应该显示什么。状态变化后 React 重新运行相关组件，并协调更新浏览器 DOM。

这类似 Android 中将屏幕拆成可复用 UI 组件并由 ViewModel 状态驱动绘制。差异是 React 组件函数不应被当作一次性 Activity：它可能在状态更新时重复执行，组件函数应该保持纯粹，不要在渲染阶段直接写数据库、发请求或修改全局对象。

其实就是类似Jetpack Compose的声明式UI。

```shell
# -p 若目录已经存在不会报错；随后进入承载所有练习项目的目录。
mkdir -p projects
cd projects

# npm create 调用脚手架；react-task 是新目录名；--template react-ts 选 React + TypeScript 模板。
npm create vite@latest react-task -- --template react-ts

# cd 进入刚被脚手架创建的项目，之后 npm install 才会针对这个 package.json。
cd react-task

# 下载 package.json 中列出的依赖到 node_modules，并生成/更新锁文件。
npm install

# 执行 package.json scripts 中的 dev；它启动 Vite 本地开发服务器。
npm run dev
```


## 组件、Props、State

组件是返回JSX的函数。   

JSX是一种描述UI的语法，会在构建时转换成JavaScript调用。  

.tsx表示TypeScript + JSX。JSX语法像HTML，但最终被工具编译成JavaScript调用，浏览器不直接懂JSX。
